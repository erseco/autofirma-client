# Documentación de arquitectura

Esta carpeta conserva las decisiones y los diseños relevantes de AutoFirma
Client. La documentación de uso explica cómo funciona la versión actual; estos
registros explican por qué se tomaron decisiones duraderas.

| Documento            | Pregunta                                            |
| -------------------- | --------------------------------------------------- |
| [ADR](adr/README.md) | ¿Qué decisión duradera se tomó y por qué?           |
| [SDD](sdd/README.md) | ¿Qué cambio relevante se diseñó y cómo se validará? |

Los ADR aceptados no se reescriben para cambiar una decisión: se sustituyen con
otro registro. Los SDD implementados se conservan como historial.
