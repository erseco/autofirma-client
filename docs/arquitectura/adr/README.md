# Registros de decisiones de arquitectura

- Los ficheros usan `ADR-NNNN-titulo.md`.
- Los identificadores son correlativos y no se reutilizan.
- Estados: `Propuesto`, `Aceptado`, `Rechazado` y `Sustituido`.
- Una decisión aceptada solo se corrige por erratas; un cambio posterior crea
  otro ADR.
- Cada afirmación técnica debe enlazar una fuente, una prueba o una ruta del
  repositorio.

Usa [la plantilla](template.md) y actualiza [el índice](records.md).
