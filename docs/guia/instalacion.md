# Instalación

```bash
npm install @erseco/autofirma-client
```

Descarga AutoScript desde el área oficial del Cliente @firma, revisa su licencia
y sírvelo desde tu propia infraestructura:

```html
<script src="/vendor/autoscript-1.9.js"></script>
```

El wrapper detectará `window.AutoScript`. También puedes inyectar un objeto
compatible para pruebas.
