# Compatibilidad

| Paquete | AutoScript probado | AutoFirma mínima | Estado |
| ------- | -----------------: | ---------------: | ------ |
| `1.9.x` |              `1.9` |            `1.9` | Activa |

El número menor sigue la línea de AutoScript. El parche identifica cambios
compatibles del wrapper:

- `1.9.0`: primera versión para AutoScript 1.9.
- `1.9.1`: correcciones del wrapper sin cambiar la línea oficial.
- `1.10.0`: futura revisión específica para AutoScript 1.10.

Esta política evita afirmar que una versión del wrapper es la misma aplicación
que AutoFirma. La compatibilidad declarada debe revisarse contra el manual
oficial y las pruebas del adaptador.
