# Ficheros de ejemplo

Estos ficheros contienen datos ficticios y sirven para probar una integración
local:

- [Texto para CAdES](files/ejemplo.txt)
- [XML para XAdES](files/ejemplo.xml)
- [PDF para PAdES](files/ejemplo.pdf)

La documentación no recibe el fichero ni su resultado. La selección y la firma
se realizan en el navegador y en la instalación local de AutoFirma. Este sitio
no incorpora un endpoint de subida.

> Una firma generada con estos ejemplos no demuestra que la integración valide
> certificados, cadenas de confianza o revocación.
